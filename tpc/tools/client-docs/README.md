# Client documents

The Word documents in the repo root are generated by these scripts. Each round of
questions to Jan is one script; `_docx_kit.py` holds the shared page design —
palette, headings, the bordered callouts, the data tables, and the `question()`
block with its cream response box.

| Script | Document |
| --- | --- |
| `make_handoff_docx.py` | Tire Finder - Catalog Format and Open Questions (Q1–Q14) |
| `make_followup_docx.py` | Tire Finder - 26in Build Notes and Follow-Up (Q15–Q24) |
| `make_catalog_docx.py` | Tire Finder - Full Catalog Notes (Q25–Q27) |
| `make_fixes_docx.py` | Tire Finder - Fixes and Additions (Q28–Q29) |
| `make_tread_docx.py` | Tire Finder - Tread Logic Rebuilt (Q30–Q32) |
| `make_nanfix_docx.py` | Tire Finder - Pressure Fix (Q33) |
| `make_record_docx.py` | Tire Finder - Where Things Stand (Q34) |
| `make_limits_docx.py` | Tire Finder - Pressure Limits and Links (Q35–Q37) |

Run one with `python tools/client-docs/make_record_docx.py` from anywhere; each
writes to a fixed path in the repo root. They need **python-docx**
(`python -m pip install python-docx`) and nothing else.

## Conventions worth keeping

- **Question numbers run continuously across documents.** The next one is Q38.
- **Write as "I", never "we", and never "Shaun" in the third person.** The
  documents go out under Shaun's name; from Jan's side there is one person
  writing them, and anything else invites him to wonder who else is involved.
- **US spelling throughout.** Jan is American. Word's spell check with
  `LanguageID = 1033` catches the strays — `behaviour`, `metre`, `grey`,
  `relabelled` have all slipped through at least once.
- **Fewer words.** Jan said so directly, and answers more readily when a
  question is one line with the reasoning underneath it.
- **Say which question matters.** Flagging one as the one worth a minute, and
  the rest as one-word answers, has reliably got all of them answered.

## Before regenerating an already-sent document

Jan and Shaun both edit these files in Word after they are generated — Jan
corrected "we agreed in the spring" to "we agreed on"; Shaun changed "until
Shaun is back" to "until I am back". Both edits were folded back into the
scripts, but **check `git diff` on the .docx before regenerating**, or a
regeneration will silently discard whatever was changed by hand.
